# Development Roadmap

## Phase 1: Foundation

- Monorepo setup.
- Next.js public routes and admin shell.
- NestJS modules, DTO validation, Swagger, Prisma schema.
- JWT auth, RBAC, local seed data.

## Phase 2: CMS Workflows

- Full property CRUD UI.
- Multi-file S3 upload UI.
- Enquiry and site visit assignment workflow.
- Agent management.
- Blog publishing workflow.

## Phase 3: Production Hardening

- HTTP-only cookie sessions.
- Audit logs for admin actions.
- Email/SMS notifications.
- CRM forwarding.
- Image transformations and moderation.
- E2E tests.

## Phase 4: Growth Features

- Saved properties.
- Property comparison.
- Mortgage calculator.
- AI recommendations.
- 3D virtual tours.
- Multi-language routing.
